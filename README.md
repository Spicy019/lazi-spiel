# LAZI

Left Alone, Continue Indefinitely. Spielen: https://spicy019.github.io/lazi-spiel/

Auf dem Handy lässt sich das Spiel als App installieren: iPhone: Teilen → „Zum Home-Bildschirm“, Android: Browser-Menü →
„Zum Startbildschirm hinzufügen“. Es läuft danach auch offline.

Dieses Repo enthält nur die automatisch gebauten Spieldateien, es ist kein Ort für Beiträge.
